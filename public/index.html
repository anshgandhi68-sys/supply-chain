Confidence is not
the same as severity

Severity describes impact. Confidence describes how strong the evidence is that a finding applies. We never merge the two.

  • ConfirmedExact version evidence matches an affected range.
  • Version unverifiedA range alone is never treated as an installed version.
  • Query failedReported as incomplete, never as clean.
